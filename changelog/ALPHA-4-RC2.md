# RusticQ Alpha 4 RC2

## Added
- Optional bar extra status icons for microphone, download speed and upload speed.
- Placement controls for the new status icons: left, center or right.

## Improved
- Quick Control notification dropdown spacing, card padding and preview sizing.
- Settings search index updated for the new bar controls.
- Settings branding updated to Alpha 4 RC2.

## Notes
- New bar status icons are disabled by default and can be enabled from **Settings → Bar → Extra status icons**.
